# MyPortfolio (FYP V1)

A Flutter-based enterprise mobile application designed for secure portfolio management and continuous professional development (CPD) tracking. 

## Core Features
* **Secure Authentication:** Integrated Google Single Sign-On (SSO) and standard email/password login.
* **PDPA-Compliant Vault:** A 2-tab (Formal/Informal) portfolio system that securely maps user-provided Google Drive links to their Cloud Firestore profiles, maintaining strict data privacy.
* **Cloud Database:** Real-time data synchronization using Firebase Cloud Firestore.

## Tech Stack
* **Frontend:** Flutter / Dart
* **Backend:** Firebase (Authentication, Firestore)
